# 注音練習

給學齡前小孩的注音符號練習網頁。單一 HTML 檔，無建置流程、無相依套件，手機瀏覽器直接開。

## 結構

```
index.html              整個 app，就這一個檔
.nojekyll               關掉 GitHub Pages 的 Jekyll 處理
audio/
  b.mp3 p.mp3 ...       37 個符號的發音
  manifest.json         需要哪些檔案
  mapping.csv           漢字 -> 目標檔名
  w/
    mao1.mp3 ...        46 個語詞的發音
scripts/
  collect_audio.py      從來源音檔挑出需要的、改成正確檔名
```

音檔沒放也能跑，會退回系統語音，發音不準，只堪測試。

## 部署到 GitHub Pages

```bash
git init && git add -A && git commit -m "init"
gh repo create zhuyin --public --source=. --push
```

Settings → Pages → Source 選 **Deploy from a branch** → `main` / `(root)`。
一兩分鐘後 `https://<帳號>.github.io/zhuyin/` 就會活。

需要注意：

- **repo 要 public**。免費帳號的 Pages 不能從 private repo 發佈。
- **檔名大小寫**。Pages 區分大小寫，macOS 預設不分。目標檔名全小寫。
- **回應有 10 分鐘快取**。改完 push 後手機可能還是舊的，測試時網址加 `?v=2`。
- 上線後在 Safari 用「加入主畫面」，會變成沒有網址列的全螢幕，小孩滑不出去。

需要 83 個檔案，清單在 `audio/manifest.json`。

來源建議用教育部《國語辭典簡編本》的「單字屬性聲音檔」，授權為
創用CC 姓名標示－禁止改作 3.0 臺灣，台灣標準發音。
下載頁在教育部國語辭典公眾授權網。禁止改作，所以轉檔可以，不要剪接變速。

```bash
python3 scripts/collect_audio.py --src ~/Downloads/moe_audio          # 試跑
python3 scripts/collect_audio.py --src ~/Downloads/moe_audio --copy   # 真的複製
```

**只放用得到的 83 個**，不要把整包幾千個檔推上來。

### 一個已知的取捨

37 個符號目前用代表字（波、坡、摸、佛……）當發音，這是「呼讀音」ㄅㄛ，
不是拼音時要用的「本音」ㄅ。認符號階段夠用，等小孩開始拼音，ㄅㄛ ＋ ㄚ 會拼不起來。
到那個階段就要自己錄那 37 個本音，檔名照 `mapping.csv` 放進 `audio/` 覆蓋掉即可。

## 三種玩法

| 模式 | 練什麼 |
| --- | --- |
| 聽音找字 | 形音配對。播符號音，四格田字格選一個 |
| 看圖拼音 | 拼音組合。給 emoji 和讀音，用符號拼出來 |
| 描寫練習 | 字形與筆順。用手指描，一筆一筆對，順序和方向都算 |

三種共用同一份熟練度資料，任何一種答對都會把該符號往上推。

## 熟練度怎麼排

簡化的 Leitner。每個符號 0~5 級，答對升一級、答錯降一級，
隔 `GAP[級數]` 題之後才會再出現，滿 5 級暫時畢業。
同時「還在學」的符號上限 4 個，學會了才引入下一個。

引入順序刻意把形近字錯開至少兩批（ㄅ/ㄆ、ㄋ/ㄌ、ㄗㄘㄙ……），
等其中一個穩了才引入對手，之後才會出現互相當干擾項的辨別題。

## 描寫模式的判定

37 個符號的筆順都內建在 `PEN` 裡：每個符號一組筆畫，每畫是一串 `[x, y]`
（0~1，左上為原點），點的順序就是下筆方向。

座標是照**黑體**（思源黑體正體中文，跟 iOS 蘋方、Android 思源同一路的字面）
量出來的，不是書法體——書法字的橫折是彎的、撇捺是帶弧度的，照著抓會讓描紅
看起來不像印刷體的注音符號。筆數與筆序則依《國語注音符號手冊》的筆形和
「由上而下、由左而右、先橫後豎、先撇後捺」。

作法是把字面渲染成點陣圖，先手抓每一筆的走向，再讓骨架沿法線爬到字面的中軸
（只准垂直於筆畫移動，不然點會沿著筆畫滑掉、把筆畫縮短），最後把幾乎直的筆畫
用最小平方法拉直。`scripts/` 沒有收這套工具，資料直接寫在 `PEN` 裡。

幾個容易抓錯、和直覺不一樣的：

- **ㄉ、ㄌ 都是 3 畫**。左上角那一小撇是獨立的一筆，不是「力」的一部分
- **ㄆ 是 3 畫**（撇、橫撇、捺），第一撇在左上角，不在中間
- **ㄊ 是 3 畫**：長橫、一筆從橫上方穿下來再折向右的撇折、最後一點
- **ㄜ 是 2 畫**：橫，加一筆從橫上方穿下來再彎出去的豎彎
- **ㄖ 中間那一筆是斜的**，不是橫的

判定是**逐筆比對**，不是看塗滿了沒有：

1. 抬起手指時，把這一筆和「這個符號的第 n 筆」各自等距切成 24 點。
2. 比三件事——平均偏差、最大偏差、起筆點距離，另外看長度比例是否離譜。
3. 三項都在容許範圍才算過，墨跡留下，進到下一筆。

所以筆數、筆順、起筆位置、下筆方向都會被判到。沒過的筆不留痕跡，
並且會講原因：

| 情形 | 回饋 |
| --- | --- |
| 這一筆倒著寫 | 方向反了，跟著紅點走 |
| 寫的是後面才該寫的筆畫 | 先寫第 n 筆 |
| 寫的是已經寫過的筆畫 | 這一筆寫過了 |
| 起筆處差太遠 | 從紅點開始寫 |
| 形狀不夠像 | 照著灰色的線描 |

同一筆連錯會自動放寬（每次 +22%，最多三次）。連錯五次就示範著幫他補上那一筆，
不會卡住，但會記在成績裡——寫的過程被幫過或錯超過一次，這題就不算答對。

畫面上永遠有淡灰描紅、下一筆的紅色起筆點和筆序號碼、
以及一排代表筆數的點（寫完一筆填一個）。停手一下會把該寫的那一筆跑一遍給他看，
跑幾趟就停著不動，省電。開了系統的「減少動態效果」會改成靜態標示。

容許範圍由家長模式的「寬鬆度」決定（1 嚴 / 2 中 / 3 鬆）。
以格子邊長為單位，寬鬆度 2 是平均偏差 0.13、起筆 0.19、最大偏差 0.27。
用模擬的童手筆跡跑過：寫得很醜也有 95% 會過，而拿別的筆畫去撞只有 0.24% 會誤收。

要改筆順就用家長模式的錄製器，它會先把內建筆順載進去讓你改，
存檔後那個符號改用你錄的，按「用回內建」還原。
核對標準筆順請查教育部「國字標準字體筆順學習網」的注音筆順。

## 家長模式

長按左上角格子圖示 1.2 秒。可以看每個符號的熟練度、調整難度與寬鬆度、
調整描寫要給多少引導、開關輪流模式、檢查音檔、改筆順、匯出匯入進度。

描寫的「引導多少」有三段：多＝每題都先跑一次筆順；中＝只有還不熟的符號才先跑
（預設）；少＝只有描紅和起筆點，想看示範自己按 ▶。

## 進度儲存

`localStorage`，key 是 `zhuyin.progress.v3`。家長頁會顯示目前實際用的儲存方式。
若顯示「記憶體」表示存不住，通常是因為用 `file://` 開啟——改用網址開。
